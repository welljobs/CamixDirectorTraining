# V2 P0/P1 使用说明：长事件、节目偏好与离线基线

日期：2026-11-13。当前交付是独立的研究基础设施，不是已经训练好的通用专业导播。V1 核心训练、schema-1 数据和现有权重保持不变。V2 尚无优化器/策略训练器，也没有真实导演盲评或真机实时验收。

## 1. 打开入口

在项目根目录运行原有 `bash start_web.command`，使用启动器给出的带本地令牌的地址打开网页。从左侧 **V2 · 长事件与节目偏好** 进入，或在同一个已认证浏览器会话打开 `/v2`。

如果之前的服务一直在运行，需在现有任务结束后正常停止并重新启动服务，才会载入新增路由。不要在训练/下载进行中直接杀进程；此次改造不会自动重启或停止任何现有服务/任务。

新入口与 V1 共用 Host/Origin/令牌保护、媒体会话、工作进程、任务锁和协作停止。不会连接第三方服务、下载权重或控制 Camix。

## 2. 最小完整工作流

1. **导入**：选择已有 V1 `session.json`，仅导入原片路径、offset、声明延迟和实际 PGM。旧点标签、`human_reviewed` 和对齐确认不会升级为 V2 审核。原片必须位于工作区 `data/`。
2. **确认身份**：填写真实原始事件 ID、用途划分、来源授权、风格条件与时钟模式。合成来源不可改成真实来源。
3. **同步审片**：使用公共时间轴和单个公共音轨检查不同机位。源时间为事件时间加 offset。界面播放器不证明时钟对齐，不模拟采集/网络延迟。未实现自动漂移校正。
4. **镜头标注**：指定有效区间、一个或多个绝对可接受机位、可选切点时间区间和适用 PGM。留空不是 KEEP；无证据的意图选未知。
5. **事件标注**：记录已经发生的关键事件及可见机位。它们是监督/评估标签，绝不作为观察输入。
6. **片段 A/B**：两个版本使用同一原片、时钟声明和公共音轨；输入各自起始机位与切换时间线，可以选 A/B/平局/不确定。保存的是具体时间线而非一个不可追溯的视频名字。改变媒体或时钟身份后，旧 A/B 必须重新绑定、重新观看与审核。
7. **保存并审核**：保存产生不可变修订；审核必须明确确认当前原片对齐及标签。姓名是本地自声明，不等于专业资质或企业身份认证。编辑使审核失效；源文件改变会拒绝沿用旧审核。
8. **索引**：预览索引允许未审核事件，但不能作训练样本。研究样本索引要求内容绑定审核与授权；合成还需显式确认。支持最长 24 小时的事件元数据，按块读取，不将整场音视频载入内存；这不是 24 小时压力测试已通过。
9. **冻结特征**：选择离线编码器、本地权重并计算/核对 SHA256。每块提取全画面视觉特征与 16kHz、过去 250ms 的音频 RMS，记录每路有效覆盖率、实际采样内容时间及按声明延迟推导的可用时间。后者不是真实网络测量。
10. **回放**：读取特征报告和缓存 ID，运行 `hold_valid` 或 `audio_rms`，观察完整事件时间线、切换、保护和缺失输入。两者都不是已学习的 V2 策略，当前视觉特征不参与这两个基线的选镜。
11. **集合检查**：检查当前选定修订的原始事件与源内容是否跨划分泄漏。工程检查通过不等于具备专业质量证据。

## 3. 当前编码器边界

- `v1_visual`：从本地 V1 检查点完整加载视觉分支并冻结；用于贯通工程链路。不能称为新增的审美能力、视频大模型或长期叙事能力。
- `mobilenet_v3_small`：支持用户提供与项目 torchvision 版本兼容的完整本地 state_dict；构造时 `weights=None`，再严格加载全部权重，不自动联网。特征为池化后的 576 维。程序不能仅凭权重字节证明它接受过何种预训练或获得了商业许可，来源需自行审核。
- 尚未接入 SigLIP/视频基础模型、主体跟踪、活跃说话人、语音语义、高层意图、长期策略训练。这些属于 P2 及以后。
- 特征编码器使用 CPU/eval/冻结权重。先用小样本测吞吐与存储，再安排更大规模，不把该提取实现宣传为 GPU 分布式流水线。

## 4. 时钟、样本与记忆约束

- 严格实时：观察内容结束时间、可用时间均不得晚于决策时刻。
- 固定延迟：决策时刻 = 输出目标事件时间 + 显式延迟；可以在预算内观察目标时间之后的内容，但不得与严格实时成绩混报。
- 视频只读过去已解码帧；不使用居中片段或未来转写。声明延迟导致负源时间时，输入无效，不能读取未来帧补齐。
- `EventFeatureSequences` 逐块输出 `observations`、独立 `targets` 和事件状态。它不是训练器；可用 `DataLoader(dataset, batch_size=None, num_workers=0)` 顺序消费，或者重建历史后再研究乱序取块。当前单事件接口拒绝多 worker，以免重复事件或丢失记忆。
- 教师 PGM 使用决策前状态（当前时刻的示范切换不能泄漏进当前输入），保持时间跨块连续；相对 PGM 上下文不一致的标签不用于评分。
- 索引里的 `context_start` 是上下文重建范围，不是已经实现长期模型记忆的证明。
- 标签平局/分歧保留；当前样本接口对同时适用的绝对可接受机位取并集，不额外推断偏好强度。

## 5. 命令行

以下在项目根目录执行，`PROJECT_ID`、修订号和权重哈希替换成真实值。不会自动下载或租用算力。

```bash
.venv/bin/python -m camix_director.v2 --workspace . status

# 显式导入媒体与 PGM，不导入 V1 标签与审核。
.venv/bin/python -m camix_director.v2 --workspace . import-v1 \
  --manifest data/your-event/session.json

# 如无素材，可独立生成合成流程样例；不会做人审。
.venv/bin/python -m camix_director.v2 --workspace . demo \
  --output data/v2_demo_manual --accept-synthetic

# 基于一个已保存修订创建预览索引；输出不得已存在。
.venv/bin/python -m camix_director.v2 --workspace . index \
  --project PROJECT_ID --revision 2 --output runs/v2/manual/index.json \
  --decision-hz 2 --chunk-steps 64 --purpose preview

.venv/bin/python -m camix_director.v2 --workspace . extract \
  --index runs/v2/manual/index.json --encoder v1_visual \
  --weights runs/your-run/best.pt --weights-sha256 EXACT_SHA256 \
  --output runs/v2/manual/feature-report.json

.venv/bin/python -m camix_director.v2 --workspace . replay \
  --index runs/v2/manual/index.json --cache-id CACHE_ID \
  --policy audio_rms --min-hold-s 2 --output runs/v2/manual/replay
```

网页上的审核入口会创建新修订；CLI 使用指定修订，不会静默跟随草稿。索引/回放输出不覆盖旧结果。特征缓存由内容寻址，可校验后复用；不完整缓存没有提交标记，不能当作成功结果。

## 6. 文件位置与兼容

- `data/v2/projects/<id>/rev-000001.json`：不可变事件修订，包含媒体身份、标签与审核。
- `runs/v2/<job>/index.json`：绑定一个修订与采样配置的长事件索引。
- `.cache/v2/features/<cache_id>/`：可重建冻结特征；提交时校验源、权重与所有分块。
- `runs/v2/<job>/feature-report.json`：缓存身份、编码器描述、输入覆盖率。
- `runs/v2/<job>/replay/`：整场非学习基线回放报告与逐时刻轨迹。
- `reports/v2-foundation/v1-baseline.json`：改造前 14 个 V1 核心源文件及 10 个已有检查点的哈希快照。

V1 核心模型/训练文件和现有权重不被覆盖；网页、任务分发器为新增 V2 功能作了小范围接入。既有完整恢复仍遵循原来的代码指纹限制，不能据此保证旧环境下的所有精确续训跨代码版本通过；保留旧源码快照或按原协议微调。

## 7. 本阶段不能宣称的能力

- 不宣称已训练通用专业导播、视觉有已验证增益、学会节奏或叙事。
- 不宣称真实导演数据充足、专业盲评完成、跨场景泛化达标。
- 不宣称 AVI 浏览器代理、自动声画同步、漂移校正或断网恢复已经完成。
- 不宣称真实 iPad 性能、Core ML V2 导出、在线影子与生产控制通过。
- 基线的相邻 tick 可接受率和粗粒度事件覆盖率不是独立样本统计，也不等于导演满意度。

下一优先级：用授权真实素材完成标注/审核与划分，冻结 P2 基准；再研究更强的视觉/声画编码器和可学习选镜策略。没有真实监督时，工程闭环与合成测试只能验收工程，不能验收节目质量。
