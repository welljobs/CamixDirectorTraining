# Camix Director V2：通用专业导播改造方案（评审稿）

- 日期：2026-11-13
- 状态：已获按优先级实施授权；本轮先交付 P0/P1 最小纵向闭环，具体状态见文末。后续模型配置与质量门槛仍为研究方案。
- 项目根目录：当前 CamixDirectorTraining 仓库根目录，不依赖固定用户名或桌面路径
- 最终目标：共享模型底座覆盖多类活动，学习画面可用性与审美、切镜时机、镜头连续性、关键事件覆盖和节目叙事。
- 初始评审稿仅新增本文档；后续实施新增独立 V2 基础模块和网页入口，未修改 V1 核心训练/已有权重，未启动真实训练或修改 Camix App。
- 范围：第一阶段仍是固定源素材下的选镜；云台、变焦、机位调度与观众反馈控制不纳入第一版。

## 1. 决策摘要

采用“共享多模态感知 + 多尺度状态记忆 + 分层因果导播策略 + 独立安全执行层”。对外可以是一个服务/部署包，不要求内部是单一无分工网络。

保留 Studio 工程底座和 V1 基线，旁路新增 V2；先解决数据协议与可验证的评价，再逐层增加能力。优先使用预训练表征和监督学习，不从零训练基础模型，不首先引入强化学习或复杂专家路由。

通用能力通过跨场景联合训练、未见场景评估和分布外回退逐步证明；不承诺“任意场景都达到专业水平”。一个场景过关不代表全部过关，界面升级不算模型升级。

## 3. V2 运行与信息边界

策略只依赖：当前已到达的各路音视频、历史播出记录、可用的节目单/风格条件和历史记忆。

- `event_time`：内容发生时间；`available_at`：该特征真正可用于决策的时间。
- 严格实时模式：`available_at <= decision_time`；固定延迟模式另声明统一预算，不混用成绩。
- 视频时序窗口必须是过去窗口，不能使用居中窗口；ASR 只能使用当时已产生的部分结果。
- 离线完整转写、未来剧情、未来镜头和回看修改不可进入实时输入。
- 已知节目单与模型预测事件分开记录；计划不等于事件已经发生。
- 不同特征采样频率由时间戳对齐，不把陈旧结果冒充当前结果。
- 所有比较对象使用相同源素材、信息边界、候选机位与延迟预算。

## 4. 模型架构

### 4.1 感知层：共享编码器 + 结构化辅助任务

输入同时保留全画面、主体局部区域和过去短视频片段；局部裁剪不能替代全画面，否则会丢失构图。第一轮只选一个预训练视觉骨干建立基线，不同时堆叠多个大模型。具体权重在授权、离线下载、吞吐与可复现性检查后确定。

视觉辅助任务：主体可见性、清晰度、曝光、抖动、遮挡、景别、主体位置、关键动作可见性。技术质量与审美、叙事相关性分开，不用固定公式宣称专业美感。

音频分开表示：原始声音、说话人/声音事件、声画关联、可选的增量语义。环境音轨不强制一一对应某个机位；允许画外音、多说话人和无法匹配。

跨机位使用机位、人物轨迹和事件 token 的交互；跨视角身份关联带置信度，匹配不确定时保留多个假设。机位槽顺序可置换，但稳定身份、视角属性和重连 generation 由适配器维护。

第一轮不依赖所有辅助模块已经成熟：没有可信标签的任务先关闭，明确记录缺失；禁止用无验证伪标签包装已获得的能力。

### 4.2 三层记忆

| 层级 | 内容 | 第一轮建议探索范围，不是性能保证 |
|---|---|---|
| 短时感知 | 每机位/主体最近动作和声画变化 | 约 2～8 秒 |
| 镜头历史 | 实际播出机位、景别、时长、重复、最近反应镜头 | 约 30～120 秒 |
| 事件摘要 | 人物关系、已发生事件、信息覆盖、节目进度 | 按整场累积，压缩/检索 |

事件记忆必须可追溯到时间戳和证据；不能把语言模型自由生成的故事当事实。可先实现结构化事件，再研究生成式摘要。

长事件分块训练时携带/重建历史状态；采用截断梯度和有界缓存，不无限反向传播。打乱训练块时先重建相应上下文，不能把不相邻块的记忆接起来。审计部署用实际 PGM；示范训练用专家 PGM；策略回放用自身 PGM，必须显式区分。

### 4.3 分层策略

1. 叙事意图：保持、交代环境、展示主体、跟随动作、展示反应、展示细节；允许软分布和未知。第一版只启用有监督证据的意图。
2. 切换时机：结合当前镜头时长与上下文预测是否适合结束当前镜头；学习可接受切点区间，不机械规定每镜几秒。
3. 机位选择：结合叙事意图、当前镜头与候选镜头关系，选择可接受机位。
4. 连续性辅助任务：前后镜头的景别、动作、视线与空间关系；缺少几何信息时不假装确定。

第一版动作仅 `KEEP`、`CUT(camera)`；叠化、混音、云台和变焦后续单独立项。

建议输出协议：切换原始分数、目标机位分布、有效候选掩码、意图分布、校准后的可靠性/拒绝标记、新记忆。原始 softmax 或排序 margin 不等于置信度；必须使用独立校准数据验证。意图标签是模型预测，不是可靠的因果解释。

### 4.4 独立执行保护

- 原始模型建议与保护后动作分别落日志，不能用保护逻辑掩盖模型错误。
- 无有效视频、信号过期或置信度不足：保持可用画面、进入已配置安全源或请求人工；当前源无效时不能盲目保持。
- 过短镜头保护、紧急事件例外和人工覆盖是显式策略；统计触发率，不能把它们称为学到的节奏。
- 时间倒退、房间变化、机位重连与身份变化触发适当状态失效；不跨事件复用记忆。
- 生产批准独立于训练与研究门槛，默认始终关闭。

## 5. 数据协议 V2

### 5.1 事件和存储

新增逻辑 `event manifest`：`original_event_id`、来源/许可、事件起止、场景标签、风格条件、人物、机位及视角、时钟映射、PGM 时间线、审片证据、划分与各版本身份。

- 全机位原片 + 时间线是主要资产；仅有成片的素材不能冒充具有候选机位的监督。
- 长事件使用分片、索引和按需读取；存储分片不改变原始事件身份。
- 可提供原始媒体与冻结特征两种训练模式。特征缓存键包括原片哈希、时间映射、预处理、编码器权重、上下文窗口与因果模式。
- 骨干权重或预处理变化使缓存失效；端到端微调不能继续使用旧冻结特征冒充新骨干输出。
- 不允许 pickle/object 数据输入；保持内容寻址、路径检查、缺失掩码和有限值校验。

### 5.2 三类新标注

| 类别 | 字段与交互 |
|---|---|
| 镜头与切点 | 起止、当前 PGM、可接受目标机位集合、允许切换的时间区间、适用上下文 |
| 事件与意图 | 已发生事件的起止、重要性、可见机位、信息覆盖、意图与置信度 |
| 片段 A/B | 相同素材/延迟的两个导播版本、胜/负/平/无法判断、节奏/覆盖/连续性等理由、审核人 |

PGM 路径改变后，原标签中的 KEEP 含义可能改变。不能直接把专家 PGM 下的相对偏好复制给模型 PGM；需要绝对候选集合、新上下文人审或标为不可评分。

多导演分歧保留为分布/多可接受答案；未知不当 KEEP。片段偏好有作用范围和来源版本，不外推到未审片段。导演与媒体授权须真实确认。

### 5.3 数据分层与拆分

- AMI 弱标签：仅作声画关联试验/预训练，单独报告，不进入专业验收。
- 真实导演示范：学习动作与切点。
- 多导演片段偏好：学习节目级质量。
- 故障与分布外数据：学习拒绝与安全退化。
- 合成数据：协议、故障和工程测试，不能替代真实质量证据。

第一轮场景矩阵建议覆盖访谈、讲台/论坛、舞台活动、仪式活动、体育/动作；素材不足的类明确空缺。记录运动、收音、照明、机位数量、遮挡等条件。总小时数不作为充分性证明，样本量应结合独立事件数、分歧和目标效果量确定。

按原始事件划分，另做场地/人物/设备/导演及活动类型留出。内部 OOD 验证用于研发，最终盲测集合单独锁定；不能反复观察最终测试集后继续调参。

## 6. 训练计划与实验顺序

### T0：对照与感知基线

固定旧模型、音频/RMS基线、保持/轮换基线；新增冻结预训练表征 + 无记忆策略，再对比音视频和短时记忆。相同划分、延迟和信息边界。第一轮优先离线特征训练，测清吞吐/存储后再申请大规模算力。

### T1：监督式导播

采用多可接受动作集合学习、切点区间监督、可信感知辅助任务和镜头连续性学习。缺失标签显式掩码，损失归一化与权重通过验证集确定，不直接套固定权重。

可探索的策略头初始搜索空间：隐藏维度 128/256、2/4 层、小规模多头注意力；这仅针对编码后策略，不代表完整基础模型规模或可部署性保证。第一轮固定一个配置做归因，再调参，避免同时改骨干、数据和损失。

### T2：长历史与高层意图

增加镜头历史和事件摘要；分别比较短记忆、中记忆、长期事件记忆的增益。学习已有证据支持的意图；没有意图标注时先做潜变量或只训练选镜，不拿自动生成标签自证叙事能力。

### T3：自身轨迹与专家纠正

在完整同步源上让模型离线切播，收集其实际 PGM 下的专家纠正，再训练策略。先做可审计的数据聚合，不直接直播探索。

固定机位的原片支持模拟不同选镜路径；若动作影响机位、演员或交互，原片不能提供可靠反事实。

### T4：节目级偏好

训练片段质量模型，先证明其对未见事件的排序与独立人审一致，再考虑保守策略优化。与纯监督模型比较；监控少切刷分、漂亮镜头刷分、事件遗漏和风格趋同。强化学习为可选实验，不是默认必做。

### T5：部署学生模型

将已经验证的教师能力蒸馏到轻量模型。教师离线分析与实时策略明确区分；未来感知教师的建议不能直接充当实时可实现动作真值。学生须重新通过质量、因果性、Core ML 数值、设备热/内存和端到端时延验收。

## 7. 分阶段交付与出口

| 阶段 | 可交付成果 | 出口/停止条件 |
|---|---|---|
| P0 协议与基准 | V2 契约、数据盘点、授权清单、冻结划分、对照回放 | 能对齐重放完整事件；因果/泄漏测试通过；没有数据则不伪造质量验收 |
| P1 数据与标注 | 长事件索引、切点/事件/A-B标注、审片与特征缓存 | 审核可追溯、缓存身份完整、旧流程兼容、可复现样本读取 |
| P2 感知与选镜 | 冻结视觉骨干、声画融合、短记忆、策略训练 | 多独立事件上优于匹配条件的基线；不足则继续数据/感知诊断 |
| P3 节奏与叙事 | 镜头历史、切点、事件记忆、高层意图 | 长片段盲评/覆盖改善；独立消融支持贡献，否则不宣称叙事能力 |
| P4 闭环偏好 | 自身路径纠正、片段质量模型、受控策略优化 | 人工质量改善且关键事件/故障不退化；不一致则不继续放大优化 |
| P5 部署与影子 | 学生模型、导出、流适配、回退与日志 | 目标设备端到端 SLO、长时故障测试与独立影子验收通过 |

每阶段都可退回数据和监督问题；不因已写代码或已消耗算力自动晋级。不提供未经数据量、硬件、人员与质量门槛校验的固定工期/成本承诺。

## 8. 模块规划（部分已落地，详见实施状态）

- `camix_director/contracts_v2.py`：数据、动作、时钟、版本协议。
- `camix_director/data_v2.py`、`prepare_v2.py`：事件索引、长事件分块、上下文重建。
- `camix_director/features_v2.py`：编码器注册、因果提取、内容寻址缓存。
- `camix_director/annotations_v2.py`：镜头、事件、片段偏好与审核版本。
- `camix_director/model_v2.py`、`memory_v2.py`：感知适配、记忆和分层策略。
- `camix_director/losses_v2.py`、`train_v2.py`：集合监督、时间区间、片段偏好与训练模式。
- `camix_director/replay_v2.py`：可重建的自身 PGM、原始建议、保护后动作。
- `camix_director/evaluate_v2.py`、`gates_v2.py`：事件级统计、盲评与分阶段门槛。

测试至少包括：未来输入扰动不影响过去输出；特征迟到/过期；缓存权重变化失效；机位槽置换；同房间断线/重连；全机位无效；长事件跨块状态一致性；未知/平局掩码；相对 KEEP 语义；完整恢复身份；原事件与特征泄漏；导出递归状态一致性。

## 9. 验收设计

- 工程：未经保护的无效候选建议单独计数；执行后不得选择无效源。无法安全恢复时要求人工介入。
- 因果：零未来信息依赖是硬门槛；缺少时间身份的数据不可进入实时能力验收。
- 技术质量：曝光/清晰/遮挡等不合格画面的播出时长，保留未选镜头情况作解释。
- 节奏与连续性：切换率、镜头长度分布、来回切换、打断动作/语义次数；不能独自替代主观质量。
- 叙事：独立审核的关键事件覆盖、漏播和呈现延迟；区分无可用机位与策略失误。
- 人工：随机匿名 A/B，允许平局，记录评审身份与分歧；建议每段至少两位独立合格评审，争议可仲裁，不伪装已具备专家资源。
- 统计：以原始事件为主要独立单位，跨片段/评审重复关系纳入分析；报告数量、效果量、置信区间与各场景结果。小样本允许“证据不足”，不把正点差当成功。
- 晋级：冻结前预登记主要指标、可接受非劣界和成功标准；专业级结论需要相对专业导演参照的独立证据，不仅是超过 RMS。
- 部署：由目标设备和业务确定端到端延迟、峰值内存、功耗/温升、断流恢复和人工覆盖 SLO；不借 Mac 模型耗时预先承诺 iPad 达标。

## 10. 兼容、资源与风险控制

- 不修改既有 schema 1 数据、冻结版本、检查点和哈希；V2 使用新 format/model family。
- V1 权重不能直接严格加载到 V2；可复用的子模块需显式映射、清单和验证，禁止称为精确续训。
- 新增依赖隔离、版本锁定；基础模型/数据授权逐项审核，下载与外部上传分别授权。
- 专业节目数据、导演审片、跨场景覆盖可能是主要瓶颈；增加 GPU 不替代这些条件。
- 首轮测一个编码器的缓存大小、提取速度、训练吞吐与内存，再决定本机/训练服务器资源；不自动购买或租用算力。
- 大模型质量与轻量部署分别研究；蒸馏可能丢失关键能力，不能默认等价。

## 11. 建议批准的第一批工作

仅批准 P0 与 P1 的最小纵向闭环，不一次启动全部重构：

1. 固化 V1 对照与实验身份；不重跑或覆盖现有最终盲测。
2. 编写 V2 契约、一个长事件索引与因果性/泄漏测试。
3. 支持镜头区间、多可接受候选与片段 A/B 标注及审核。
4. 接入一个经授权与资源验证的冻结视觉编码器；保留替换接口。
5. 跑通“授权全机位 → 标注 → 特征 → 训练样本 → 完整事件回放 → 基线报告”。
6. 有足够真实审核数据后进入 P2；没有则仅宣布协议/工程闭环完成，不宣布审美或叙事进步。

评审时需确认：目标活动范围、严格实时/延迟模式、目标部署设备、已有全机位素材与许可、可参与评审的导演、可用训练硬件。这些决定排期和预算，但不影响上述方向评审。

## 12. 研究依据与适用边界

- SigLIP 2（2025）：预训练视觉语义与局部表征的候选路线，不是专业导播能力证明。
- Ross、Gordon、Bagnell（AISTATS 2011）：DAgger/策略自身状态分布的数据聚合思路；本项目需验证其具体实现。
- Christiano 等，Deep Reinforcement Learning from Human Preferences（2017，后续修订）：片段比较学习目标的研究依据；不能外推为导播任务的效果、标注量或成本保证。

所有新配置、时间跨度、模块和验收组织方式都是本项目建议，后续用真实数据、独立人审与设备证据修订。
